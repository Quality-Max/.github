# Getting help

- [Documentation](https://docs.qualitymax.io/): product behavior, setup, and troubleshooting.
- [Web app](https://app.qualitymax.io): hosted account and project workflows.
- [Public product guide](https://github.com/Quality-Max/qualitymax): features, examples, and the tool directory.

For a tool bug, open an issue in that tool's repository with its version and a minimal reproduction. For documentation feedback, use the [product guide issue tracker](https://github.com/Quality-Max/qualitymax/issues).

For private product questions, contact **contact@qualitymax.io**. For vulnerabilities, follow [SECURITY.md](SECURITY.md). Never post credentials, customer data, or private execution artifacts in a public issue.
